# 📚 Athena Library Management System & Dual Portals

A modern, highly animated, full-featured Library System website built with React, Vite, and Tailwind CSS. Featuring a **brand-new split-screen visual login template**, **two dedicated portal experiences**, an **About Us** institution showcase, and a comprehensive **Contact Us** hub.

---

## 🌟 Refreshed Split-Screen Visual Login Experience

### 1. 🖼️ Atmospheric Photographic Canvas (Left Wing)
- **High-Resolution Library Architecture**:
  - *Patron Mode*: Warm, atmospheric, illuminated modern stacks with ambient natural light.
  - *Staff Mode*: Grand cathedral Long Room library with historic arches and skylights.
  - Smooth parallax zoom animation on hover (`group-hover:scale-105 transition-transform duration-1000`).
- **Floating Glassmorphic Badges**:
  - Live status indicator: `🟢 Open Today • 08:00 AM – 10:00 PM`
  - Dynamic mode tag: `📚 READER SANCTUARY` vs `🛡️ STAFF OPS TERMINAL`
  - Daily Literary Inspiration card with rotating literary quotes from Borges, Hemingway, Einstein, and Martin.
  - Patron Rating badge (`⭐ 4.9 / 5.0`).

### 2. 🎛️ Unified Glassmorphic Control Panel (Right Wing)
- **Segmented Dual-Portal Slider**:
  - Switch smoothly between **"Patron Sanctuary"** (Golden Amber & Emerald Glow) and **"Librarian Staff"** (Indigo & Cyber Purple Glow).
- **Instant 1-Click Fast Evaluation Profiles**:
  - *Eleanor Vance*: Literature Student with 2 active loans and 1 overdue fine for instant testing.
  - *Marcus Chen*: Tech Researcher & Community Patron.
  - *Sarah Jenkins, MLS*: Chief Librarian (Level 4 Clearance).
  - *David O'Connor*: Circulation Desk Officer (Level 2 Clearance).
- **Interactive Form Elements**:
  - Email / Patron ID / Staff Keycard inputs with clear icons.
  - Password / PIN input with toggle visibility eye icon.
  - Instant new patron registration tab.

## 🚀 Running the Website

The server is currently live at:
👉 **`http://localhost:3000`**

### Windows File Explorer:
- Double-click **`run.bat`** or **`start.bat`** in `e:\Codes\Library system\`.

### Terminal:
```powershell
cmd /c "npm run dev"
```
Or with Node:
```powershell
node server.js
```
